# Sortimentsstrategie Embroidery Republic

> **Stand 2026-07-21.** Dieses Dokument denkt das Sortiment **vom Kunden her**,
> nicht vom Herstellerkatalog. Es ist die Grundlage für den langfristigen Ausbau
> und soll über Jahre tragen, ohne dass die Struktur umgebaut werden muss.
>
> Die reine Produktliste liegt getrennt in
> [`produktkatalog-vollstaendig.md`](produktkatalog-vollstaendig.md).
> Dieses Dokument beantwortet: **Was erwartet ein Kunde von uns – und warum?**

## Teil 1 — Zielgruppenanalyse

Für jede Gruppe: Was wird bestellt, was gemeinsam, welche Eigenschaften zählen,
was darf nicht fehlen.

### 1.1 Unternehmen (Büro, Dienstleistung, Vertrieb)

| | |
|---|---|
| **Bestellt** | Piqué-Polo, Softshelljacke, Weste, Sweatjacke, T-Shirt |
| **Gemeinsam** | Polo + Softshelljacke + Weste als „Corporate-Set", Damen **und** Herren in identischer Farbe |
| **Eigenschaften** | repräsentativ, formstabil nach Wäsche, Mischgewebe gegen Knittern, XS–5XL |
| **Unverzichtbar** | **Piqué-Polo, Softshelljacke, Weste** |

**Entscheidend: Nachbestellbarkeit.** Ein Unternehmen bestellt zwei Jahre später
zehn Stück nach – in exakt derselben Farbe. Marken mit stabilem Farbstandard und
Langzeitverfügbarkeit sind hier mehr wert als der günstigste Preis. Ein
ausgelistetes Produkt kostet uns den Kunden.

### 1.2 Handwerksbetriebe

| | |
|---|---|
| **Bestellt** | Workwear-T (schwer), Workwear-Sweat, Arbeitsjacke, Weste, Softshell |
| **Gemeinsam** | **Ganzjahres-Set in einer Farbe**: T-Shirt (Sommer) + Sweat (Übergang) + Jacke (Winter) |
| **Eigenschaften** | robust 180–220 g, 60 °C waschbar, reißfest, Taschen, dunkle Farben |
| **Unverzichtbar** | **schweres Workwear-T-Shirt, Workwear-Sweatshirt, Softshelljacke + Weste** |

Veredelung fast immer zweiteilig: kleiner Stick auf der Brust, großer Schriftzug
auf dem Rücken. Große Größen (4XL/5XL) sind hier kein Randthema.

> **Warnschutz (EN ISO 20471)** ist ein eigenes Feld: Die bedruckbare Fläche ist
> normativ begrenzt, weil Reflexstreifen und Leuchtfläche nicht überdeckt werden
> dürfen. Das ist ein **eigener Produkttyp mit eigenen Regeln**, nicht ein
> weiteres T-Shirt – siehe Roadmap.

### 1.3 Gastronomie

| | |
|---|---|
| **Bestellt** | Polo (kurz + **langarm**), T-Shirt, **Schürze**, Weste |
| **Gemeinsam** | Polo + Schürze |
| **Eigenschaften** | pflegeleicht, Mischgewebe, farbecht bei häufiger Wäsche, überwiegend schwarz |
| **Unverzichtbar** | **schwarzes Piqué-Polo, Langarm-Polo, Schürze** |

Die Schürze ist der Artikel, nach dem hier zuerst gefragt wird – wir haben sie
nicht. Siehe Roadmap.

### 1.4 Hotellerie

| | |
|---|---|
| **Bestellt** | Rezeption: Hemd/Bluse + Weste · Housekeeping: Polo/Tunika · Restaurant: Polo + Schürze |
| **Gemeinsam** | **rollenbezogene Sets** in einheitlicher Hausfarbe |
| **Eigenschaften** | repräsentativ, langlebig, über Abteilungen hinweg farblich abgestimmt |
| **Unverzichtbar** | **Weste, Langarm-Polo** |

Hotels denken in Rollen, nicht in Artikeln. Wer Rezeption, Housekeeping und
Restaurant aus einer Hand einkleiden kann, gewinnt den Auftrag.

### 1.5 Arztpraxen und Pflegeeinrichtungen

| | |
|---|---|
| **Bestellt** | **Kasack/Tunika**, Polo, T-Shirt, Fleecejacke |
| **Gemeinsam** | Kasack + Fleecejacke (Stationen sind kühl) |
| **Eigenschaften** | 60–95 °C waschbar, helle Farben, bewegungsfreundlich, chlorbeständig |
| **Unverzichtbar** | **Kasack** – ohne ihn ist die Gruppe nicht bedienbar |

Kasack ist ein eigener Schnitt, kein Polo. Heute können wir Polo und Fleecejacke
liefern, den Kernartikel nicht. Siehe Roadmap.

### 1.6 Feuerwehr, Rettungsdienst, THW

| | |
|---|---|
| **Bestellt** | T-Shirt, Polo, Sweatshirt, Hoodie, Softshelljacke, Weste |
| **Gemeinsam** | Ganzjahres-Set in Wehrfarbe, meist mit **Namensstick + Ortsangabe** |
| **Eigenschaften** | robust, dunkelblau/rot, **hoher Baumwollanteil** |
| **Unverzichtbar** | **schweres Baumwoll-T-Shirt, Sweatshirt, Softshelljacke** |

**Fachlich wichtig:** Reines Polyester ist hier problematisch – es schmilzt bei
Hitze und Funkenflug. Baumwolle oder baumwolldominante Mischungen sind Standard.
Ein Performance-Polyestershirt ist für diese Gruppe das falsche Produkt, auch
wenn es technisch bedruckbar ist.

Zusätzlich: personalisierte Einzelstücke (Name je Mitglied) bei gleichzeitig
großer Gesamtmenge – das ist ein Sonderfall der Bestellabwicklung.

### 1.7 Vereine

| | |
|---|---|
| **Bestellt** | T-Shirt, Hoodie, Zip-Hoodie, Trainingsjacke, Polo |
| **Gemeinsam** | Hoodie + T-Shirt, häufig mit Name und Nummer |
| **Eigenschaften** | preisgünstig in Menge, Farbvielfalt, **Kindergrößen**, nachbestellbar |
| **Unverzichtbar** | **günstiges T-Shirt, Hoodie, Zip-Hoodie** |

Vereine brauchen dieselbe Ware in Erwachsenen- **und** Kindergrößen. Fehlen die
Kindergrößen, wandert der ganze Auftrag ab.

### 1.8 Schulen und Abschlussklassen

| | |
|---|---|
| **Bestellt** | **Hoodie (Leitartikel)**, Zip-Hoodie, College-Sweat, T-Shirt |
| **Gemeinsam** | Hoodie mit Namensliste auf dem Rücken („Abi-Pullis") |
| **Eigenschaften** | günstig, **viele Farben**, große Größenrange, **Termintreue** |
| **Unverzichtbar** | **Hoodie in breiter Farbauswahl** |

Stark saisonal: Abschlusskollektionen laufen konzentriert zwischen Januar und
April, oft mit hartem Termin. Farbauswahl und Liefertreue entscheiden.

### 1.9 Kindergärten

| | |
|---|---|
| **Bestellt** | Kinder-T-Shirt, Kinder-Hoodie, Latzschürze, Turnbeutel |
| **Gemeinsam** | T-Shirt + Turnbeutel |
| **Eigenschaften** | Größen 98–152, weich, schadstoffgeprüft |
| **Unverzichtbar** | **Kinder-T-Shirt, Kinder-Hoodie ohne Kordel** |

> **Sicherheitsnorm DIN EN 14682:** In Kinderkapuzen bis Größe 134 sind
> Kordeln unzulässig. Ein Kinder-Hoodie muss kordellos sein – das ist kein
> Ausstattungsdetail, sondern Voraussetzung.

### 1.10 Sportteams

| | |
|---|---|
| **Bestellt** | Funktions-T-Shirt, Trainingsjacke, Hoodie, Polo |
| **Gemeinsam** | Trikot + Trainingsjacke + Hoodie als Teampaket |
| **Eigenschaften** | atmungsaktiv, Polyester, Nummern und Namen, oft Kindergrößen |
| **Unverzichtbar** | **Funktions-T-Shirt, Trainingsjacke** |

Fachlich: Stickerei auf Funktionsware braucht Stickvlies, sonst verzieht der
Stoff. Auf hellem Polyester ist Sublimation möglich, auf Baumwolle nicht – die
Veredelungsart hängt am Material, nicht am Wunsch.

### 1.11 Eventveranstalter und Promotion

| | |
|---|---|
| **Bestellt** | Basic-T-Shirt in hoher Stückzahl, Polo, Warnweste, Cap |
| **Gemeinsam** | T-Shirt + Cap |
| **Eigenschaften** | **Preis vor allem**, Signalfarben, kurzfristig verfügbar |
| **Unverzichtbar** | **günstigstes T-Shirt im Sortiment, Promotion-Weste** |

Hier zählt der Einstiegspreis. Ein sehr günstiges Basic-Shirt ist Pflicht – auch

### 1.12 Merchandise, Bands, Streetwear

| | |
|---|---|
| **Bestellt** | **Oversized-T**, Heavyweight-Hoodie, Premium-T, Cap, Tote Bag |

## Teil 2 — Zwei strukturelle Befunde

Diese Punkte stehen hier, weil sie die Sortimentsstrategie stärker begrenzen als
jede Produktauswahl.

### 2.1 Keine Mindestbestellmenge — ENTSCHIEDEN und umgesetzt

**Grundsatzentscheidung (Juli 2026): Privatkunden gehören zu den
Kernzielgruppen. Es gibt keine Mindestbestellmenge.**

Vorher galt `MINIMUM_QUANTITY = 5`, und `calculatePrice` rechnete intern mit
`Math.max(quantity, 5)` – wer ein Einzelstück bestellte, zahlte stillschweigend
fünf. Privatkunden, Creator und kleine Vereine waren damit faktisch
ausgeschlossen.

**Technisch umgesetzt, kaufmännisch offen.** Die Architektur unterstützt
einmalige Rüstkosten (Regeltyp `setup_fee`), die pro Auftrag anfallen und sich
auf die Stückzahl verteilen. **Standardmäßig stehen sie auf 0 € und sind
deaktiviert** – die Preisstrategie wird später anhand der echten
Einkaufspreise, Produktionszeiten und Margenziele festgelegt.

Mengenstaffeln: **1 · 5 · 10 · 25 · 50 · 100 · 250 · 500**.

Konfigurierbar allein über die Preisregeln, ohne Eingriff in die
Berechnungslogik (Nachweis siehe `src/lib/pricing/__tests__/einzelstueck.test.ts`):

| Strategie | Konfiguration |
|---|---|
| keine Rüstkosten | Standard (`isActive: false`) |
| einmal je Auftrag | `multiplier: 'once'` |
| je Veredelungsposition | `multiplier: 'per_position'` |
| je Motiv | `multiplier: 'per_element'` |
| nur eine Position | zusätzlich `printView: 'back'` |
| nur eine Veredelungsart | Regel nur in der jeweiligen Regelliste |
| unterschiedlich je Verfahren | eigener Betrag je Regelliste |
| befristete Aktion | `validFrom` / `validUntil` |
| nur in einem Mengenfenster | `minQuantity` / `maxQuantity` |

> **Offen (kaufmännisch):** Ob und in welcher Höhe Rüstkosten erhoben werden.
> Ebenso die Versandkalkulation, die historisch „÷5 wegen Mindestmenge"
> gerechnet wurde (siehe `pricingRules.ts`).

### 2.2 Der Größenbereich deckt zwei Zielgruppen nicht

Aktuell S–3XL bzw. XS–XXL. Es fehlen:

- **Kindergrößen 98–152** → Kindergärten, Vereine, Schulen, Sportteams
- **4XL/5XL** → Handwerk, Feuerwehr

Beides sind reine Datenpunkte (Größentabelle + Fotos), **kein neuer
Produkttyp**.

## Teil 3 — Sortimentsarchitektur

Damit der Katalog über Jahre wächst, ohne umgebaut zu werden, wird er über
**drei feste Achsen** beschrieben. Jedes künftige Produkt – auch Cap, Tasche
oder Handtuch – bekommt einfach seine Koordinaten und braucht keine neue
Struktur.

### Achse 1 — Anwendungsfeld
`Corporate` · `Workwear & Schutz` · `Hospitality & Care` · `Team & Verein` ·
`Merch & Creator` · `Privat & Geschenk`

### Achse 2 — Funktion am Körper
`Basisschicht kurz` (T-Shirt, Polo) · `Basisschicht lang` (Longsleeve,
Langarm-Polo) · `Mittelschicht` (Sweatshirt, Hoodie, Zip-Hoodie) ·
`Außenschicht` (Jacke, Weste) · `Kopf & Accessoire` (Cap, Beanie, Tasche) ·
`Objekt & Heimtextil` (Schürze, Handtuch, Decke)

### Achse 3 — Qualitäts- und Materialstufe
`Einstieg` · `Standard` · `Premium` · `Bio/Fairtrade` · `Performance` ·
`Schutz/Norm`

**Warum das trägt:** Die heutigen neun ProductTypes sind die Achse-2-Werte
„Basisschicht" bis „Außenschicht". Caps und Taschen sind `Kopf & Accessoire`,
Schürzen und Handtücher `Objekt & Heimtextil`. Die Achsen 1 und 3 bleiben
unverändert. Ein neuer Produkttyp erweitert Achse 2 – die Struktur bleibt.

## Teil 5 — Roadmap: künftige Produktgruppen

Noch **nicht** integrieren – aber die Architektur ist darauf vorbereitet.

| Stufe | Gruppe | Achse 2 | Neuer Typ? | Warum |
|---|---|---|---|---|
| **R1** | **Kindergrößen** bestehender Artikel | wie Elternartikel | **nein** | Vereine, Schulen, Kindergärten, Sport – größter Hebel ohne Code |
| **R1** | **Große Größen 4XL/5XL** | wie Elternartikel | **nein** | Handwerk, Feuerwehr |
| **R2** | **Schürzen** | Objekt & Heimtextil | ja | Gastro, Hotel, Kindergarten, Privat |
| **R2** | **Caps** | Kopf & Accessoire | ja | Event, Merch, Sport, Handwerk |
| **R2** | **Taschen / Beutel** | Kopf & Accessoire | ja | Merch, Kindergarten, Event, Messe |
| **R3** | **Beanies** | Kopf & Accessoire | ja | Handwerk, Verein, Winter-Merch |
| **R3** | **Kasack / Berufsbekleidung Pflege** | Basisschicht | ja | Arztpraxen, Pflege |
| **R3** | **Handtücher** | Objekt & Heimtextil | ja | Verein, Sport, Hotel, Privat |
| **R4** | **Warnschutz EN ISO 20471** | Außenschicht | ja + Regelwerk | Handwerk, Bau – normative Flächenbegrenzung |
| **R4** | **Hosen / Shorts** | – | ja | Handwerk, Sport |
| **R4** | **Decken, Kissen, Heimtextil** | Objekt & Heimtextil | ja | Privat, Geschenk |

**Technische Einordnung:** Nur R1 kommt ohne neuen Produkttyp aus. Alles ab R2
braucht einen neuen `ProductType` und – wichtiger – **ein eigenes
Geometriemodell**, weil das aktuelle Modell den Maßstab aus Körperlänge und
Brustbreite ableitet. Eine Cap, eine Tasche oder ein Handtuch hat beides nicht.

## Teil 6 — Was daraus für die Reihenfolge folgt

Ohne Vorgriff auf Ihre Entscheidung – die Analyse ergibt diese Rangfolge nach
Wirkung je Aufwand:

1. **Mittelschicht schließen** (Sweatshirts, Hoodies, Damenvarianten) – trifft
   Schulen, Vereine, Feuerwehr, Merch gleichzeitig; nur eine Lücke, aber die
   größte.
2. **Außenschicht aufbauen** (Softshelljacke + Weste, Herren/Damen) – erschließt
   Corporate, Handwerk, Hotel; der Typ `vest` ist ungenutzt.
3. **Kindergrößen** – erschließt drei Zielgruppen ohne eine Zeile Code.
4. **Bio/Fairtrade durchgängig** – heute 4 von 43; ohne Nachweis sind Gemeinden
   und NGOs nicht bedienbar.
5. **Merch-Segment** (Oversized, Heavyweight, Premium-Basic) – wachsender Markt,
   heute gar nicht besetzt.
6. Danach die Roadmap-Gruppen ab R2.

**Erledigt:** Die Mindestbestellmenge ist abgeschafft (Teil 2.1). Privat- und
Creator-Geschäft sind damit fester Bestandteil der Strategie – das hebt
Geschenk- und Einzelstückartikel (Punkt 4.6) sowie eine breite Farbauswahl in
der Priorität.

Offen bleibt eine Entscheidung:

- **Wie breit soll Workwear werden?** Handwerk mit Warnschutz ist ein eigener
  Markt mit eigenen Normen – lohnend, aber kein Nebenbei-Segment.
